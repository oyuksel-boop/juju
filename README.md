# Juliet's Maths Islands

A P3 maths practice game (Scotland P3, with P1/P2 warm ups and P4 challenges) starring Pip the Puffin.

Play: https://oyuksel-boop.github.io/maths-islands/

## What is inside
- 10 islands and 75 skills: Number Nook, Add and Subtract Bay, Times Tables Glen, Fraction Falls, Money Market, Clock Tower, Measure Moor, Shape Castle, Data Harbour, Puzzle Peak.
- Every skill has three levels: Warm up, Core and Challenge. Stars unlock the next level.
- Questions are generated fresh each time with pictures (blocks, clocks, coins, fractions, charts, shapes). Recent questions are remembered so they do not repeat.
- Hint, Learn and Read aloud buttons on every question. A worked explanation after a wrong answer.
- Rewards: 1 sticker for every 25 correct answers, 10p for every 2 stickers. 32 stickers to collect, with shiny versions.
- Piggy Bank screen shows this week and past weeks. Weeks run Monday to Sunday.
- Grown ups area (lock button, top right): weekly payouts, activity chart, reset.

## Files
- index.html: the whole game (art, questions and app in one file)
- sw.js: offline support. Change VERSION inside it whenever index.html is updated.
- manifest.webmanifest and icons: lets the tablet install it as an app.

Progress is saved on the device (browser storage). Clearing Chrome site data will clear progress.
